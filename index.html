What this file is

A self-contained page, not a connected app

This is a single HTML file with the docket data written into it. It doesn't need installing, doesn't need an internet connection, and doesn't talk to Clio or anyone else's computer. Opening it means double-clicking the file.

This copy

The original docket, restored

This version carries the full de-identified working docket — 102 matters, case numbers as they were originally assigned from the Clio export (cases 100–102 are three that existed in the old ongoing tracker with no matching intake record, carried over as their own entries). Every matter can still be edited or removed individually, or cleared in bulk from the "Sample data" toolbar group if you'd rather start from empty and build up via Add matter or Import matters from CSV.

Client names

The sample data has none — the "Client name" field is optional and entirely up to you

Out of the box, this file has no real client names anywhere — every sample matter's client name field is blank. If you fill names in locally, they're saved the same way every other edit is: to this browser, tied to this exact file, never sent anywhere. That also means the moment you'd consider sharing, backing up to a wider location, or hosting this file anywhere more visible than Dillex's own secure storage, treat it as containing real client data and handle it accordingly.

Storing and backing it up

Treat it exactly like a Word or Excel file

  • Save it wherever Dillex's normal backup already covers — network drive, firm OneDrive/SharePoint, or the same location other case documents live.
  • To share with a colleague, send the single .html file — nothing else is needed.
  • To refresh it with up-to-date figures later, ask again with the latest export — it can be regenerated, not synced.
Editing, importing and exporting

Edits, imports and notes all save to this PC and this file location only

Every dropdown, category pill, text field and note box saves to the browser's local storage, tied to this exact file in this exact folder on this exact computer. Edits won't appear if the file is copied elsewhere or opened by a colleague from their own copy — each copy keeps its own separate edits. Use Backup edits to save your changes as a separate JSON file, and Restore edits to reapply them to a fresh copy of this dashboard later.

+ Add matter on the All matters page opens a single-entry form — month comes first since that's the one thing every matter needs, client name and everything else is optional or defaults sensibly.

Import from CSV reads a spreadsheet straight from your computer — nothing is uploaded anywhere. Use CSV template first for the expected columns. Imported matters carry a green "imported" tag and can be removed with the ✕ button.

+ Add new month extends the docket beyond the built-in Pre-May–July run. When you add one, any matter still sitting in the previous month that isn't finished/concluded or closed automatically moves forward into the new month, so nothing open quietly falls out of view. It suggests the next calendar month automatically, but you can type any label you want.

Each of the four matter pages can export its currently filtered rows to PDF via the browser's own print dialog (choose "Save as PDF") — this works offline, without any external service.

Given the subject matter

Handle the file the way you'd handle any case list

  • Keep it inside Dillex's normal secure storage rather than personal cloud accounts or personal email.
  • Delete or archive old snapshots properly rather than letting stray copies build up.
  • If several people at the firm need to view and jointly edit the same live list, a static file like this isn't the right long-term tool — that needs an actual shared, permissioned system.
